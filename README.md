# Social Media Analytics

A Python project that analyzes social media posts using sentiment analysis and data visualization.

## Features
- Data cleaning and preprocessing
- Sentiment analysis using VADER
- Hashtag extraction and analysis
- Politician activity analysis
- Social media platform comparison
- Data visualization

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VADER Sentiment

## Run the Project

```bash
pip install -r requirements.txt
python main.py
```
